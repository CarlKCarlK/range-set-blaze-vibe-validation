Implementation shape. AlgoE is toRangeSet ∘ internalAddCMap _ input () ∘ toUnitMap. AlgoELen is the same composition through internalAddCMapLen, returning an ELenResult with the set and the cached Nat count. See AlgoE.lean.

Main theorems. internalAddE_toSet, internalAddELen_setResult, and internalAddELen_cachedLength, in the same invariant style as CLen/DLen: a correct incoming count yields a count equal to the result cardinality. The _toSet corollary is kept only for parity with the four existing Len APIs. internalAddE_eq_internalAddA joins the cross-algorithm equalities in CrossAlgorithm.lean.

Proof reuse. No fresh induction over insertion. Both Len theorems are CMapLen's theorems transported across the bridge, each a two-line proof. The set-semantics proof is CMap's overwrite theorem plus one by_cases on membership in the input.

New shared mathematics, added at the end of Basic.lean under "Range sets as Unit-valued range maps":

RangeSetBlaze.toUnitMap and RangeMapBlaze.toRangeSet, with canonicality carried by List.pairwise_map and the equal-value clause of Run.before.
toRangeSet_toUnitMap (round trip is the identity, @[simp]), toRangeSet_toSet (forgetting values keeps the support), toRangeSet_cardinality (keeps the count).
One private lemma stating that first-match interpretation is defined exactly on the union of the run ranges, for any value type.
