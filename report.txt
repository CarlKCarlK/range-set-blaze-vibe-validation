AlgoE / AlgoELen completion report

Implementation
--------------

- `RangeSetBlaze/AlgoE.lean` defines `internalAddE` by converting a
  `RangeSetBlaze` to a canonical `Unit`-valued `RangeMapBlaze`, calling
  `internalAddCMap`, and erasing the values.
- `internalAddELen` uses the same conversion with `internalAddCMapLen` and
  preserves the returned `Nat` cache.
- `RangeSetBlaze.lean` imports and exports both APIs.

Proof architecture
------------------

The cached-length proof reuses `internalAddCMapLen_cachedLength`; no map
insertion arithmetic was duplicated. The main public results are:

- `internalAddE_toSet`
- `internalAddELen_setResult`
- `internalAddELen_cachedLength`
- `internalAddELen_toSet`

The stable shared bridge moved to `Basic.lean`:
`RangeMapBlaze.support_eq_rangesToSet`, stating that a run list's support is
the union of its carried intervals, without requiring canonicality.

Cleanup and API review
----------------------

- Removed the unused set-conversion helper and the duplicate private support
  theorem from AlgoE.
- Kept conversion constructors and cache bookkeeping private.
- No unrelated Len or algorithm refactor was performed.
- The proof sketch is: Unit-specialize CMap; erase values; use the CMapLen
  cache theorem; identify map support with the erased set.
